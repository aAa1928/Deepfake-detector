# End-to-End Deepfake Audio & Voice-Clone Detector

A Python project scaffold for detecting AI-generated or cloned speech using raw audio modeling approaches.

## Structure

- `data/`: raw, interim, and processed datasets
- `src/`: package source code
- `models/`: saved model artifacts
- `notebooks/`: exploration and experimentation
- `scripts/`: utility and entry-point scripts
- `configs/`: configuration files
- `tests/`: automated tests
- `reports/`: generated figures and analysis output
- `artifacts/`: run outputs and exported artifacts
